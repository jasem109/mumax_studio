    Workflow
    
        
      
          
    1. Geometry: set the mesh and build the magnet from shapes, imported STL models, images or your own inside(x, y, z) code.
      2. 
          
    2. Setup: material, initial state, what to record. Drive: fields and currents with any pulse shape.
      3. 
          
    3. Press Run. The script is generated (see the Script page) and runs on the chosen device. Ctrl+Enter runs whatever is in the editor.
      4. 
          
    4. While it runs, type commands in the console, e.g. B_ext = vector(0, 0, 0.1), Save(m), Run(1e-9).
      5. 
        
    
        
    Pulse and waveform functions
    
        
    
          
    Gaussian(t, t0, fwhm)unit-height Gaussian
    
          
    Pulse(t, t0, width)rectangular
    
          
    Trapezoid(t, t0, rise, flat, fall)linear edges
    
          
    SincPulse(t, t0, fc)flat spectrum up to fc
    
          
    Chirp(t, f0, f1, T)linear frequency sweep
    
          
    SquareWave(t, f, duty), TriangleWave, SawtoothWaveperiodic
    
          
    PulseTrain(t, t0, width, period, n)repeated pulses
    
          
    GaussianWavePacket(t, t0, fwhm, f)microwave burst
    
          
    Waveform(ts, vs), LoadWaveform("w.csv")arbitrary, piecewise linear
    
        
    
        
    Spatial profiles and custom fields
    
        
    
          
    B_ext.Add(ShapeMask(shape, vector(0,0,1)), A*f(t))field only inside a shape
    
          
    GaussianSpot(x0, y0, fwhm, v), StripLine(x0, w, v)focused spot, antenna strip
    
          
    AddFieldTerm(q)any vector quantity, e.g. Mul(Const(0.1), m)
    
          
    AddFieldTerm(fn) (Python)fn(x, y, z[, t]) → (Bx, By, Bz)
    
        
    
        
    Shapes
    
        
    All mumax3 shapes and Transl, RotX/Y/Z, Scale, Repeat, Add, Sub, Intersect, Xor, Inverse, plus
          Polygon(xs, ys), RegularPolygon(n, d), Ring(do, di), Sphere(d), Torus(D, d),
          STLShape("part.stl", 1e-9) and, in Python, SetGeom(lambda x, y, z: ...). EdgeSmooth = 8 smooths edges as in mumax3.
    
        
    Spin–orbit torque (this fork)
    
        
    
          
    JSOTcurrent density (A/m²); z-component used, a scalar works
    
          
    SPINHALL, HFLoverHDLspin Hall angle, field-like/damping-like ratio
    
          
    SOThickness, SOTFixedLayerthickness (0 = mesh), polarization σ
    
        
    
        
    Devices
    
        
    The CPU (NumPy + SciPy FFT) always works. Install CuPy for your GPU, pip install cupy-cuda12x (NVIDIA) or cupy-rocm-* (AMD, Linux), then choose GPU or Auto.
    
        
    Colours
    
        
    Vectors use the mumax3 colour wheel: hue = in-plane direction, white = +z, black = −z.
