    Workflow
    
        
      
          
    1. Geometry: set the mesh and build the magnet from shapes, imported STL models, images or your own inside(x, y, z) code.
      2. 
          
    2. Setup: material, initial state, what to record. Drive: fields and currents with any pulse shape.
      3. 
          
    3. Press Run. Before it starts, the app shows where the results go (<folder>\<name>.out); the folder chip in the top bar changes it. The script is generated (see the Script page) and runs on the chosen device. Ctrl+Enter runs whatever is in the editor.
      4. 
          
    4. While it runs, type commands in the console, e.g. B_ext = vector(0, 0, 0.1), Save(m), Run(1e-9).
      5. 
        
    
        
    Pulse and waveform functions
    
        
    
          
    Gaussian(t, t0, fwhm)unit-height Gaussian
    
          
    Pulse(t, t0, width)rectangular
    
          
    Trapezoid(t, t0, rise, flat, fall)linear edges
    
          
    SincPulse(t, t0, fc)flat spectrum up to fc
    
          
    Chirp(t, f0, f1, T)linear frequency sweep
    
          
    SquareWave(t, f, duty), TriangleWave, SawtoothWaveperiodic
    
          
    PulseTrain(t, t0, width, period, n)repeated pulses
    
          
    GaussianWavePacket(t, t0, fwhm, f)microwave burst
    
          
    Waveform(ts, vs), LoadWaveform("w.csv")arbitrary, piecewise linear
    
        
    
        
    Spatial profiles and custom fields
    
        
    
          
    B_ext.Add(ShapeMask(shape, vector(0,0,1)), A*f(t))field only inside a shape
    
          
    GaussianSpot(x0, y0, fwhm, v), StripLine(x0, w, v)focused spot, antenna strip
    
          
    AddFieldTerm(q)any vector quantity, e.g. Mul(Const(0.1), m)
    
          
    AddFieldTerm(fn) (Python)fn(x, y, z[, t]) → (Bx, By, Bz)
    
        
    
        
    Shapes
    
        
    All mumax3 shapes and Transl, RotX/Y/Z, Scale, Repeat, Add, Sub, Intersect, Xor, Inverse, plus
          Polygon(xs, ys), RegularPolygon(n, d), Ring(do, di), Sphere(d), Torus(D, d),
          STLShape("part.stl", 1e-9) and, in Python, SetGeom(lambda x, y, z: ...). EdgeSmooth = 8 smooths edges as in mumax3.
    
        
    Spin–orbit torque (this fork)
    
        
    
          
    JSOTcurrent density (A/m²); z-component used, a scalar works
    
          
    SPINHALL, HFLoverHDLspin Hall angle, field-like/damping-like ratio
    
          
    SOThickness, SOTFixedLayerthickness (0 = mesh), polarization σ
    
        
    
        
    mumax⁺ scripts (Python)
    
        
    Python scripts that import mumaxplus run on a built-in implementation of the mumax⁺ API: World, Grid, Ferromagnet, Antiferromagnet and Ferrimagnet (two sublattices with afmex_cell, afmex_nn, latcon), parameters set from numbers, arrays or functions, timesolver.run / solve, minimize, relax, and mumaxplus.util (shapes, initial states, Voronoi grains, plotting). Figures from plt.show() are saved as PNG files in the output folder. If the official mumaxplus package is installed it takes precedence.
    
        
    from mumaxplus import World, Grid, Ferromagnet
world = World(cellsize=(500e-9/128, 125e-9/32, 3e-9))
magnet = Ferromagnet(world, Grid((128, 32, 1)))
magnet.msat, magnet.aex, magnet.alpha = 800e3, 13e-12, 0.02
magnet.magnetization = (1, 0.1, 0)
magnet.minimize()
print(magnet.magnetization.average())
    
        
    Viewer and OVF files
    
        
    There is one viewer, in 3D. It follows the running simulation live, or plays OVF files: drop one or more files on it, use OVF…, or press view next to a snapshot on the Files page (the other snapshots in that folder become frames you can play). Drag to orbit, right-drag or Shift-drag to pan, scroll to zoom; top gives the familiar 2D picture of a film. Slice crops the box and thins the glyphs. While the Geometry page is open the viewer shows the magnet being built: 2D edit to drag shapes on one layer, 3D to see the whole body coloured by region.
    
        
    Files, folders and deleting
    
        
    The Files page lists the output folder. Tick files or whole .out folders and press Delete, or use the bin button on a row. Deleting cannot be undone. The output of a run that is still going is protected until you stop it.
    
        
    Claude
    
        
    The Claude panel writes scripts from a description, fixes a failing script, explains one or reviews its physics. It uses Claude Code when it is installed and signed in (Claude Pro or Max subscription), or an Anthropic API key. To let Claude Desktop or Claude Code run simulations themselves, register the MCP server once:
    
        
    claude mcp add mumax-studio -- mumax-studio mcp
    
        
    Devices
    
        
    The CPU (NumPy + SciPy FFT) always works. For an NVIDIA GPU install pip install "cupy-cuda12x[ctk]"; for AMD on Linux, cupy-rocm-*. Each GPU is tested when the app starts; the device menu lists every GPU that passed and greys out the ones that did not, with the reason in the tooltip. The choice is remembered and applies from the next Run.
    
        
    Colours
    
        
    Vectors use the mumax3 colour wheel: hue = in-plane direction, white = +z, black = −z.
